# Nuxt Studio

Adds browser-based content editing and MDC component metadata. Requires the `content` module.
Run `pnpm dev` and open a content page to edit local files with Studio.
For production editing, set `STUDIO_GITHUB_CLIENT_ID` and `STUDIO_GITHUB_CLIENT_SECRET` and configure the repository in `nuxt.config.ts`.
Open `/admin/studio` to sign in on the deployed site.
